# A0MP 大金风管机

已确认方案：为华为账号下 A0MP 设备提供独立 climate 实体，支持开关、基本模式、16–32℃整数设温、六档风速；加入现有 HomeKit 桥接。1501 小米设备不属于本次范围。

协议依据：https://smarthome-drcn.dbankcdn.com/device/guide/A0MP/A0MP.json （2026-09-28，测试夹具为公开 Profile，无账户数据）。

模式：1 自动、2 制冷、3 制热、4 送风、5 除湿。100–104 专有模式不映射为其他模式。风速：0 自动、1 低、2 中、3 高、4 强、5 超强。开启某模式时先设模式再开机，任一步失败即上报，不跨通道重试。实际命令行为待用户测试。

状态来自设备报告，命令成功不伪造状态；未知模式保持未知。没有室温或压缩机活动数据，不用设定温度冒充室温。HomeKit 的界面和模式支持范围由 HA 自带桥接决定，风速等完整控制保留在 HA。

实施顺序：产品适配和1℃步长元数据 → 协议/失败行为回归测试 → GitHub提交验证 → 备份并覆盖三个生产文件 → 重启HA验证六台华为实体 → 明确实体列表加入现有桥接。实物不自动测试。

回滚：从桥接移除新增六台空调，恢复旧 climate.py、manifest.json，移除 prod_A0MP.py 并重启；保留灯光、电视、账户、配对存储。
